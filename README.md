# WaveLog PRO — Трекер силовой программы

Личный веб-трекер силовой программы с волнообразной периодизацией (объём / средняк / сила), авто-подсказкой рабочего веса, офлайн-режимом (PWA) и хранением данных в браузере (IndexedDB).

## Основные возможности

- **Волнообразная периодизация**: 3-недельный цикл, 5 тренировочных дней (Пн, Вт, Ср, Пт, Сб), 20 слотов упражнений с предписаниями на 3 зоны (`str` — Сила, `mid` — Средняк, `vol` — Объём).
- **Авто-расчёт рабочего веса**: алгоритм на базе опорного e1RM ($0.5 / 0.3 / 0.2$ за 3 последние сессии), целевого RPE зоны, потолков `% cap` и шагов округления (`inc`).
- **Быстрые действия в зале**:
  - Бледная подсказка веса в полях ввода (`placeholder ~40%`).
  - Кнопка «Принять подсказку» (автозаполнение всех незаполненных подходов).
  - Кнопка «Как в прошлый раз» (копирование из прошлой сессии).
  - Чипы RPE 6–10 с шагом 0.5.
  - Быстрый таймер отдыха (60с, 90с, 120с, 180с).
- **Дизайн Brutalist Gym**:
  - Чистый чёрный фон (`#000000`), белый текст, фирменная жёлтая обводка (`#facc15`).
  - Строгие прямоугольные углы (`rounded-none`).
  - Mobile-first: крупные цели касания (высота строк $\ge 48\text{ px}$), цифровая клавиатура.
- **Аналитика и прогресс**:
  - График e1RM по базовым движениям (присед, жим, становая) на Recharts.
  - Динамика недельного тоннажа (кг).
  - Недельный объём рабочих подходов по мышечным группам (прямые и суммарные).
  - Баннер усталости (v1.5).
- **Полная автономность (PWA & Offline)**:
  - Данные хранятся только на устройстве в IndexedDB (Dexie).
  - Экспорт и импорт полной базы данных в JSON.
  - Журнал событий (`events`, append-only) для будущей интеграции ИИ-агента (v2).

## Стек технологий

- **Фреймворк**: React 18, Vite, TypeScript (strict)
- **Стилизация**: Tailwind CSS v4, Lucide React
- **Стейт-менеджмент**: Zustand
- **Хранение данных**: Dexie (IndexedDB)
- **Графика и даты**: Recharts, date-fns (локаль `ru`)
- **PWA**: vite-plugin-pwa (Service Worker, работа без сети)
- **Тестирование**: Vitest (14 unit-тестов доменной логики)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Запуск тестов
npm test

# Сборка production
npm run build
```
